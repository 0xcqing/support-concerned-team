# Have You Tried Turning It Off

This program sends one funny single-line reply a hopeless tech support agent gives a desperate customer. That reply is the whole entry and nothing else.

## How it runs

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
